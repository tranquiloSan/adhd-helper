# A stretch can be started in the past

Both count-up tools began at the moment you pressed Start. So the thing that
happened often - working for an hour, then noticing the tool was not running -
had no answer except to start from zero and lose the hour, or not bother. Worse,
the gap read as the tool's failure: it was there, it was unused, therefore it had
distracted you into forgetting it. The honest reading is the opposite. You
surfaced; the tool just had nowhere to put the time you had already done.

So Start now takes an optional earlier beginning. Elapsed asks for a length -
"should have been running for 2h" - because the tool is a duration you glance at
and the timer already speaks that grammar. Day asks for a clock time - "started
at 09:00" - because that is how it already reads its end. Each field is behind a
"forgotten to start?" link rather than on the screen, since most starts are just
Start and a field that rarely has an answer is a question the screen should not
keep asking.

Three lines drawn around it.

It is offered only from idle. A running stretch's start stays fixed until reset,
the same lock the countdown has and for the same reason: being able to nudge the
figures of something already underway is how the account stops being trusted.

Nothing is checked past the preview. The typed value is turned into "2 hours,
started 14:00" before you commit, and a mistyped "20h" is caught by reading that,
not by a rule - the same bargain `0007` struck for a mistyped end. A time still
to come today is read as yesterday's, so an evening's work is nameable; there is
nothing else "22:00" typed at 09:00 could mean.

On Day it moves one line and no more. The track is anchored at now and the
countdown is `endsAt - now`, so an earlier start changes only the "3 hours in"
sentence. That the figure would otherwise be a small lie - "started 14:00, 0
minutes in" for a day you had been at since nine - is reason enough.

What this does not become is automatic. The tool does not start itself on the
first keystroke of the day, or nudge you to start it, or keep a background count
you can adopt. Day "does nothing until started" is in the glossary, Elapsed
"never sounds" is the point of it, and an always-on tracker that you retro-claim
is a different tool with a different bargain. The intrusive thought is answered
by making the return cost nothing, not by removing the choice to return.

The invariant from `0002` still holds. Start plus elapsed plus breaks lands on
the wall clock: back-dating sets the start and elapsed becomes `now - start`, so
the two agree from the first frame, and breaks are zero until the first pause.
